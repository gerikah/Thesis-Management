# Thesis Management Portal

This project is split into a Vite frontend and a PHP/MySQL backend for XAMPP.

## Project Structure

- `frontend/` - HTML, CSS, and TypeScript browser code.
- `backend/` - PHP API endpoints and database connection scripts.
- `dist/` - production frontend build output generated by Vite.

## Run Locally

**Prerequisites:** Node.js and XAMPP/MySQL.

1. Install dependencies:
   `npm install`
2. Start Apache and MySQL in XAMPP.
3. Run the frontend:
   `npm run dev`
4. Open the Vite URL shown in the terminal, usually `http://localhost:3000`.

The frontend calls the backend through:

- `http://localhost/Thesis-Management/backend/fetch_theses.php`
- `http://localhost/Thesis-Management/backend/save_thesis.php`

To rebuild the database tables, open:

`http://localhost/Thesis-Management/backend/fix_db.php`
